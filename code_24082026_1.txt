# Loan Manager App

An Android app for managing loan customers, payments, and records — works offline, all data stored locally.

## ✅ Features
- 📋 Customer info: Name, Address, Job, Phone
- 📸 Camera: take & save customer photo
- 📄 Scan: scan IC / ID / passport
- 📍 GPS: auto‑capture customer location
- 💰 Loan amount input
- 📊 3 repayment schemes:
  - Daily (next day = Day 1)
  - 8‑Day (disburse day = Day 1)
  - 10‑Day (disburse day = Day 1)
- ✍️ Adjustable interest rate & overdue penalty rate
- ⏰ Due date reminders (local notifications)
- ⚖️ Overdue penalty calculation
- 💾 Full CRUD: add / view / edit / delete records
- 📎 Temporary build — for this use only

## 📱 Compatibility
- Android 8.0+
- Optimized for realme 12

## 🛠️ Tech Stack
- Kotlin + Jetpack Compose
- SQLite local database
- CameraX, ZXing scanning, Google Location Services

## 📲 Build & Install
1. Clone or download ZIP
2. Open in **Sketchware**, **Acode**, or **Android Studio**
3. Build APK → install on your phone
4. Grant permissions → start using!
